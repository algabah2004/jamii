## Rituels

- **Lundi (15 min)** : le chef de projet présente les tâches de la semaine dans le tableau GitHub Projects.
- **Chaque jour, par écrit** : chacun déplace ses cartes et laisse un commentaire si quelque chose le bloque.
- **Vendredi (30 min)** : démo de ce qui a été fusionné, puis on choisit les priorités de la semaine suivante.
