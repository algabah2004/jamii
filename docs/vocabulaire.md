# Vocabulaire de l'interface

**Règle n°1 : n'importe quel développeur ou commerçant doit comprendre chaque écran du premier coup, sans rien apprendre.**

Pas de thème (sport ou autre), pas de métaphore, pas de jargon interne. Un bouton dit ce qu'il fait.

| Mot à utiliser | À éviter |
|---|---|
| Profil | Carte joueur, avatar |
| Communauté | Club, guilde |
| Antenne locale (ville, pays) | — |
| Équipe | Squad, vestiaire |
| Demande (besoin d'une PME) / Mission (travail accepté) | Ticket, contrat |
| Besoin, Orientation (ce que Jamii propose pour un besoin) | Diagnostic, lead, prospect |
| Carte de compétences | Score, note, classement |
| Publier, Déployer, Mettre en ligne | Marquer un but, lancer |
| Réponse acceptée | Passe décisive |
| Impact par pays | Classement des sélections, saison |
| Défi du mois | — |
| Cercle | Groupe, clan, guilde |
| Tour | Round, manche, saison |
| Tech Tontine | — |
| Griot (l'assistant IA du cercle) | Coach, bot, IA |

## Tech Tontine : les seuls mots imagés autorisés

La tontine est connue partout sur le continent : on cotise chacun son tour, et chaque tour un membre reçoit le pot. Ici, on cotise **du travail**. Ces mots sont autorisés **uniquement** pour ce module, et toujours avec leur sens :

| Mot | Sens exact |
|---|---|
| **Tech Tontine** | Le nom du module. Sous-titre obligatoire au premier affichage : « Construisez à tour de rôle le projet de chaque membre ». |
| **Cercle** | Un groupe de 4 à 6 développeurs qui s'engagent ensemble. |
| **Tour** | La période pendant laquelle tout le cercle construit le projet d'un membre. Un tour, c'est un projet Jamii. |
| **Ordre de passage** | L'ordre des tours, tiré au sort par le serveur. |
| **Griot** | Le nom de l'assistant IA du cercle. Il est toujours présenté avec sa fonction : « le Griot, l'assistant qui planifie et résume le tour ». |

Les boutons restent explicites : « **Créer un cercle** », « **Rejoindre le cercle** », « **Déposer mon idée** », « **Tirer l'ordre au sort** », « **Livrer le tour** ». Aucun autre mot imagé (pot, cotisation, caisse…).

## Exemples

- ✅ Le bouton dit « **Déployer** ». Après le déploiement, on affiche « ✅ Ton projet est en ligne », avec le lien.
- ✅ Le menu dit « **Communautés** », « **Demandes** », « **Projets** ».
- ❌ Un bouton dont il faut deviner l'action.

## Récompenses

On peut féliciter l'utilisateur (une petite animation ou un badge « Premier projet en ligne »), mais le texte reste toujours explicite.

## Langues

L'interface est d'abord en français, puis en anglais. Les clés de traduction reprennent les mêmes mots (`profile`, `community`, `request`, `mission`, `circle`, `turn`). « Tech Tontine » et « Griot » ne se traduisent pas.
