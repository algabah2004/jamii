# Vocabulaire de l'interface

**Règle n°1 : n'importe quel développeur ou commerçant doit comprendre chaque écran du premier coup, sans rien apprendre.**

Pas de thème (sport ou autre), pas de métaphore, pas de jargon interne. Un bouton dit ce qu'il fait.

| Mot à utiliser | À éviter |
|---|---|
| Profil | Carte joueur, avatar |
| Communauté | Club, guilde |
| Antenne locale (ville, pays) | — |
| Équipe | Squad, vestiaire |
| Demande (besoin d'une PME) / Mission (travail accepté) | Ticket, contrat |
| Publier, Déployer, Mettre en ligne | Marquer un but, lancer |
| Réponse acceptée | Passe décisive |
| Impact par pays | Classement des sélections, saison |
| Défi du mois | — |

## Exemples

- ✅ Le bouton dit « **Déployer** ». Après le déploiement, on affiche « ✅ Ton projet est en ligne », avec le lien.
- ✅ Le menu dit « **Communautés** », « **Demandes** », « **Projets** ».
- ❌ Un bouton dont il faut deviner l'action.

## Récompenses

On peut féliciter l'utilisateur (une petite animation ou un badge « Premier projet en ligne »), mais le texte reste toujours explicite.

## Langues

L'interface est d'abord en français, puis en anglais. Les clés de traduction reprennent les mêmes mots (`profile`, `community`, `request`, `mission`).
